# WIN-011 | client-windows/AwCollector + Status | 一般 | 部分 HttpClient 未设超时，健康探测硬编码
- 描述：`AwCollectorService._aw` 未设置 `Timeout`，依赖默认 100s，`FetchAwInfoAsync`/`FetchSupportedBucketsAsync` 失败仅 Log 后返回空，未向上区分超时与连接拒绝；`StatusWindow` 探活硬编码 `http://127.0.0.1:5600/api/0/buckets/` 与 `Http` 静态实例 `Timeout=3s`，不跟随配置的 `AW_BASE_URL` 环境变量，环境变量变更后状态页仍探固定地址。
- 位置：src/client-windows/Pim.Client.Core/Services/AwCollectorService.cs:31,283-322; src/client-windows/Pim.Client.App/StatusWindow.xaml.cs:15,82-89
- 问题：
  ```csharp
  _aw = new HttpClient { BaseAddress = new Uri(AwBase) }; // 无 Timeout
  var awProbe = await ProbeEndpointAsync("http://127.0.0.1:5600/api/0/buckets/"); // 硬编码
  private static readonly HttpClient Http = new() { Timeout = TimeSpan.FromSeconds(3) };
  ```
- 风险：ActivityWatch 未启动时采集线程阻塞 100s；状态中心显示与实际采集使用的地址不一致，误导排障；静态 HttpClient 生命周期与应用一致但无 DNS 刷新 handling。
