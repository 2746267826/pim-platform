# WIN-002 | client-windows/ApiClient | 严重 | SendWithAuthRetryAsync 未包裹网络异常且 EnsureSuccessStatusCode 直接抛出
- 描述：`ApiClient.SendWithAuthRetryAsync` 对 `await request()` 和 `EnsureSuccessStatusCode()` 均无 try/catch，仅对 401 做一次刷新重试。其余 4xx/5xx 直接抛出 `HttpRequestException`，调用方若未 catch（如 `DaemonHeartbeatReporter`/`PlannedOfflineReporter`）则异常冒泡。
- 位置：src/client-windows/Pim.Client.Core/Services/ApiClient.cs:134-166
- 问题：
  ```csharp
  private async Task<T?> SendWithAuthRetryAsync<T>(Func<Task<HttpResponseMessage>> request, CancellationToken ct)
  {
      var response = await request(); // 无 try/catch，HttpRequestException/TaskCanceledException 直接抛出
      // ... 401 刷新逻辑 ...
      response.EnsureSuccessStatusCode(); // 500/400 直接抛，业务 Code 未判断
      return await response.Content.ReadFromJsonAsync<T>(ct);
  }
  ```
- 风险：任何网络抖动或服务端 500 都会以异常形式中断采集/心跳/注销流程；`DaemonHeartbeatReporter.ReportAsync:18` 与 `PlannedOfflineReporter.ReportAsync:14` 无 catch，依赖上层，易遗漏导致未处理异常崩溃。
