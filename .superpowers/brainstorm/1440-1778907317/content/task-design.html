任务视图关键细节

任务行布局

优先级圆点 + 标题描述 + 任务本标签 + 时长 + 排程时间/截止日期 + 优先级标签 + 状态标签 + 详情箭头

筛选与搜索

顶部 Chip 筛选栏：全部 / 未排程 / 高优先级 / 今日。右侧搜索框支持标题模糊搜索

交互行为

点击行打开任务详情对话框（编辑）。从列表拖拽任务到收件箱面板可取消排程。底部"新建任务"按钮打开空白详情对话框

状态标识

已排程 = 绿色"已排程"标签 + 显示排程时间。收件箱 = 灰色"收件箱"标签 + 显示截止日期（红色）。优先级：高红/中黄/低绿
