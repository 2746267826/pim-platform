# WIN-015 | client-windows + client-shell-windows | 提示 | 文件并发写入无原子性与共享控制
- 描述：`DaemonConfig.Save`/`ShellConfig.Save`/`AuthService.SaveToken` 均使用 `File.WriteAllText` 非原子写入且未指定 `FileShare`，若多进程（Shell 与 Daemon 同时读写）或杀进程中断，可能产生半截 JSON；`KeyStatsOneClickFixService.ReadLogExcerpt` 正确使用 `FileShare.ReadWrite`，但其他读路径 `File.ReadAllText` 默认独占，读时可能因写锁抛出 `IOException` 被静默吞掉。
- 位置：src/client-windows/Pim.Client.App/DaemonConfig.cs:32-35; src/client-windows/Pim.Client.Core/Services/AuthService.cs:101-116; src/client-shell-windows/Pim.Shell.App/ShellConfig.cs:27-32
- 问题：
  ```csharp
  File.WriteAllText(FilePath, JsonSerializer.Serialize(this)); // 非原子，未使用临时文件+重命名
  var json = File.ReadAllText(FilePath); // 可能因写锁抛 IOException 被外层 catch 吞掉
  ```
- 风险：配置文件损坏后静默回退为空，用户感知为“配置丢失”；Token 写入半截后下次 `TryRestoreTokenAsync` 反序列化失败返回 false，需重新登录。
