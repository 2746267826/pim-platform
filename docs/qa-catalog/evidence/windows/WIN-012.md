# WIN-012 | client-shell-windows/ShellWindow | 一般 | 升级检查无超时精细处理与版本比对错误
- 描述：`ShellWindow.InitializeAsync` 中 `Task.Run` 发起 `HttpClient(Timeout=3s)` 拉取 `/api/client/shell/latest`，异常被空 catch 吞掉，无重试；版本比对委托 `UpdateChecker.IsNewer` 使用 `string.CompareOrdinal` 字符序而非语义化版本，`10.0.0` 会被判为小于 `9.0.0`，已在 `docs/qa-catalog/CATALOG.md PIM-040` 提及于 `Pim.Shell.App/UpdateChecker.cs`。
- 位置：src/client-shell-windows/Pim.Shell.App/ShellWindow.xaml.cs:32-39; src/client-shell-windows/Pim.Shell.App/UpdateChecker.cs:5-11
- 问题：
  ```csharp
  _ = Task.Run(async () => {
      using var http = new HttpClient { Timeout = TimeSpan.FromSeconds(3) };
      var latest = await http.GetFromJsonAsync<LatestDto>($"{_serverUrl.TrimEnd('/')}/api/client/shell/latest");
      if (latest?.windowsVersion != null && UpdateChecker.IsNewer("0.1.0", latest.windowsVersion)) // 硬编码 current
          Dispatcher.Invoke(() => { UpdateBar.Visibility = Visibility.Visible; });
  } catch { } // 吞错
  // UpdateChecker
  return string.Compare(remote.Trim(), current.Trim(), StringComparison.Ordinal) > 0; // 字符序
  ```
- 风险：字符序导致大版本号升级被漏检；fire-and-forget 任务无 CancellationToken，窗口关闭后仍可能访问 Dispatcher 已释放对象；异常吞掉导致升级失败无日志。
