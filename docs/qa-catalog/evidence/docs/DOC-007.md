# DOC-007 | docs/module-development-guide.md | 严重 | 业务接口默认鉴权与 PcTracker 四组读接口 AllowAnonymous 冲突
- 描述：模块开发指南要求业务接口默认 `RequireAuthorization()`，但 PcTracker 将核心读接口设为匿名。
- 文档位置：module-development-guide.md:244-245 认证节 和 166 MapEndpoints 示例
- 文档承诺：`业务接口默认 .RequireAuthorization()`，仅 `/health` 等极少数匿名且需明确理由
- 代码实际：`src/modules/Pim.Module.PcTracker/PcTrackerModule.cs:580` `app-knowledge`、`:724` `app-signatures`、`:927` `categories`、`:1007` `productivity` 四组 `AllowAnonymous()`，`curl -s http://127.0.0.1:5239/api/v1/pc/categories` 返回 200 而非 401（`evidence/pc-anonymous.txt`）
- 差异：文档要求默认鉴权，代码将敏感枚举接口暴露为匿名，可未登录获取应用知识库与生产力看板
