# WIN-018 | client-windows+client-shell-windows | 一般 | 默认 HTTP 明文且 WebView 调试常开
- 描述：`ClientDefaults.DefaultServerUrl=http://127.0.0.1:5858` 默认明文 HTTP，`ServerAddress.IsInsecure` 仅在 `SetupWindow` 中弹框确认后仍允许 http；`ShellWindow` 与 `EmbeddedWebViewHost` 均 `AreDevToolsEnabled=true`、`AreDefaultContextMenusEnabled=true`，生产包未关闭。
- 位置：src/client-windows/Pim.Client.Core/ClientDefaults.cs:5; src/client-shell-windows/Pim.Shell.App/ServerAddress.cs:25-26; src/client-shell-windows/Pim.Shell.App/SetupWindow.xaml.cs:23-29; src/client-windows/Pim.Client.App/EmbeddedWebViewHost.cs:33-34; src/client-shell-windows/Pim.Shell.App/ShellWindow.xaml.cs:24-25
- 问题：
  ```csharp
  public const string DefaultServerUrl = "http://127.0.0.1:5858";
  public static bool IsInsecure(string? normalizedServerUrl) => normalizedServerUrl is not null && normalizedServerUrl.StartsWith("http:", ...);
  ```
