# WIN-016 | client-windows/AuthService | 严重 | 明文存储 Token 于本地文件
- 描述：`AuthService.SaveToken` 将 `AccessToken`/`RefreshToken`/`ExpiresAt` 等以明文 JSON 写入 `%LOCALAPPDATA%/PIM/token.json`，`TryRestoreTokenAsync` 明文读回。`PersistedToken` 未加密、未使用 DPAPI 或 `ProtectedData`，任何本地进程或备份软件可直接读取。
- 位置：src/client-windows/Pim.Client.Core/Services/AuthService.cs:13-16,69-116
- 问题：
  ```csharp
  private static readonly string TokenDir = Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "PIM");
  private static readonly string TokenPath = Path.Combine(TokenDir, "token.json");
  File.WriteAllText(TokenPath, JsonSerializer.Serialize(data)); // 明文
  var json = await File.ReadAllTextAsync(TokenPath);
  var data = JsonSerializer.Deserialize<PersistedToken>(json); // 明文
  ```
- 风险：Token 明文落盘违反 `AGENTS.md B5 "Tokens live in memory or encrypted storage only"`；恶意软件、`adb backup` 类比或用户误分享 `%LOCALAPPDATA%/PIM` 即可劫持账户，与 `Pim.Api` JWT 长期有效叠加扩大窗口。
