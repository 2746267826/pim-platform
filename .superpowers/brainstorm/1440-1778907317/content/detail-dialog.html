编辑器对比

日程编辑器字段

日历本选择 → 标题 → 全天开关 → 开始/结束时间（点击弹日期+时间选择器） → 地点 → 备注 → 颜色选择 → 状态（已确认/暂定/已取消） → 重复规则 → 阻挡自动排程开关 → 保存/删除

任务编辑器字段

任务本选择 → 标题 → 描述 → 地点 → 预计时长（预设 Chip） → 截止时间 → 优先级（高/中/低） → 重复 → 提前提醒 → 自动排程/允许拆分/锁定排程 三个开关 → 保存/删除
