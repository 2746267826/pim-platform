# PIM-043 | Mobile | 严重 | /location/points 无幂等，同请求重复落库

- 描述：`POST /api/v1/mobile/location/points` 无 `batchId` 或去重键，每次请求均 `INSERT` 新行，相同 `deviceId+recordedAtUtc+lat/lng` 发2次产生2行，并发4次产生4行。
- 复现：
  ```bash
  API=http://127.0.0.1:15733
  TOKEN_A=$(cat /tmp/token_s1a.txt)
  curl -s -X POST $API/api/v1/mobile/location/points -H "Authorization: Bearer $TOKEN_A" -H "Content-Type: application/json" -d '{"deviceId":"session1-device-A","recordedAtUtc":"2026-09-21T11:00:00Z","latitude":39.9,"longitude":116.4,"horizontalAccuracyMeters":10,"provider":"gps","sourceKind":"manual","rawJson":"{}"}' > /tmp/loc1.json
  curl -s -X POST $API/api/v1/mobile/location/points -H "Authorization: Bearer $TOKEN_A" -H "Content-Type: application/json" -d '{"deviceId":"session1-device-A","recordedAtUtc":"2026-09-21T11:00:00Z","latitude":39.9,"longitude":116.4,"horizontalAccuracyMeters":10,"provider":"gps","sourceKind":"manual","rawJson":"{}"}' > /tmp/loc2.json
  cat /tmp/loc1.json | python3 -m json.tool | grep id
  cat /tmp/loc2.json | python3 -m json.tool | grep id
  PGPASSWORD=62f0a50bb963bb648f8e400399def95a psql -h 127.0.0.1 -p 5432 -U opencode -d pim_test -c "SELECT count(*) FROM mobile_location_points WHERE device_id='session1-device-A' AND recorded_at_utc='2026-09-21T11:00:00Z';"
  # 第一次 1，第二次 2，并发再发2次后 4
  ```
- 预期：同 `deviceId+recordedAtUtc` 第二次应幂等返回同一 `id`，DB `count=1`。
- 实际：每次新 `id`（如 `adb79f61-...` vs `db6b77f4-...`，并发 `185ca658-...`/`260fe2b3-...`），`count=2` → `4`，无唯一约束。
- 证据：`evidence/api/session1/location_req1.json`、`location_req2.json`（返回 `id` 不同），`src/modules/Pim.Module.Mobile/Services/MobileLocationService.cs:39-69` `SavePointAsync` 直接 `Add+SaveChanges`。
