# WIN-014 | client-windows/TrayIcon+Logger | 一般 | 资源未释放与日志路径竞争
- 描述：`TrayIcon.LoadIcon` 与 `TrayManager.LoadIcon` 从 `Application.GetResourceStream(...).Stream` 创建 `Icon` 后未释放原始 `Stream`；`Logger.Initialize` 每次启动 `Directory.CreateDirectory` 并创建 `CompactJsonFormatter` 写入日滚动文件，但 `LogFilePath` 使用 `DateTime.Now` 惰性计算且非线程安全，跨天时 `Initialize` 的 `pim-daemon-.jsonl` 与 `LogFilePath` 的 `pim-daemon-20260824.jsonl` 不一致。
- 位置：src/client-windows/Pim.Client.App/TrayIcon.cs:42-58; src/client-shell-windows/Pim.Shell.App/TrayManager.cs:30-39; src/client-windows/Pim.Client.App/Services/Logger.cs:11-21,59-60
- 问题：
  ```csharp
  var streamInfo = Application.GetResourceStream(new Uri("pack://application:,,,/Pim.Client.App;component/app.ico"));
  if (streamInfo?.Stream is not null) return new Icon(streamInfo.Stream); // Stream 未 Dispose
  private static string? _logFilePath;
  public static string LogFilePath => _logFilePath ??= Path.Combine(LogDir, $"pim-daemon-{DateTime.Now:yyyyMMdd}.jsonl");
  ```
- 风险：GDI 句柄与 Stream 句柄轻微泄漏，长时间运行托盘图标多次 `Show()` 可能累积；日志路径不一致导致“查看日志”按钮打开文件与实际写入文件不一致，用户排障困惑。
