# WIN-013 | client-windows/AwCollector | 一般 | HttpResponseMessage 未释放导致句柄泄漏
- 描述：`AwCollectorService.FetchNewEvents` 以阻塞方式调用 `GetAsync` 后，仅在非成功状态码时直接 `return new()` 未释放 `HttpResponseMessage`；成功路径通过 `response.Content.ReadFromJsonAsync` 读取后亦未 `Dispose`。`GetFromJsonAsync` 路径虽自动释放，但此分支绕过封装。
- 位置：src/client-windows/Pim.Client.Core/Services/AwCollectorService.cs:354-376
- 问题：
  ```csharp
  var response = _aw.GetAsync(url, _cts.Token).GetAwaiter().GetResult();
  if (!response.IsSuccessStatusCode) return new(); // 未 Dispose
  var all = response.Content.ReadFromJsonAsync<List<RawAwEvent>>(cancellationToken: _cts.Token)
      .GetAwaiter().GetResult() ?? new(); // response 未 Dispose
  ```
- 风险：每次定时采集（30s）泄漏一个 `HttpResponseMessage` 及其底层 socket/stream，长时间运行后句柄数持续增长，触发 `SocketException` 或 `ObjectDisposedException`。
