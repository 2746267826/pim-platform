# WIN-006 | client-windows/KeyStatsCollector+AwCollector | 一般 | 周期任务无执行时长保护与重叠防护缺失
- 描述：`KeyStatsCollectorService.Start` 使用 `PeriodicTimer(1分钟)` 串行执行 `CollectAndUploadAsync`，但 `CollectAndUploadAsync` 内 `GetFromJsonAsync` 失败后吞掉异常并返回，未区分瞬时故障与持续故障；`AwCollectorService` 使用 `SemaphoreSlim(1,1)` 保证单次执行，但 `BackfillAsync` 与 `CollectAndUploadAsync` 共用同一 `_collectionGate`，长时间回填（14天）将阻塞定时采集，最长可达数分钟，且无超时中断。
- 位置：src/client-windows/Pim.Client.Core/Services/KeyStatsCollectorService.cs:43-61; src/client-windows/Pim.Client.Core/Services/AwCollectorService.cs:47-91,113-143
- 问题：
  ```csharp
  // KeyStatsCollector 1分钟周期，无任务执行超时
  using var timer = new PeriodicTimer(TimeSpan.FromMinutes(1));
  await CollectAndUploadAsync();
  while (await timer.WaitForNextTickAsync(_cts.Token)) { await CollectAndUploadAsync(); }
  // AwCollector Backfill 与定时采集共用同一信号量，无独立超时
  await _collectionGate.WaitAsync(_cts.Token);
  ```
- 风险：回填期间定时任务饥饿，实时采集延迟；若本地 KeyStats API 卡死（未设超时或超时过长），周期任务堆积导致守护进程响应变慢，退出时 `_cts.Cancel` 需等待当前周期完成。
