# WEB-011 | /calendar | 一般 | 日历分页page=-1未校验
- 描述：日历分页接口未对 `page` 做 `Clamp(1,)` 校验，`page=-1` 仍200返回数据而非400。
- 复现：`curl -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:5860/api/v1/calendar/events?start=...&end=...&page=-1&pageSize=5"`
- 预期：400 或自动纠正为1
- 实际：200 返回正常 `items`，`Skip(-1)` 未报错
- 证据：`db-write2.log` 中 `neg page 200 ...`
