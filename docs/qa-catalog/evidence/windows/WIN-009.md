# WIN-009 | client-windows/DaemonConfig | 一般 | 配置缺失默认值与损坏静默回退
- 描述：`DaemonConfig.Load()` 在文件不存在、JSON 损坏或反序列化为 null 时均 catch 后返回 `new()` 默认配置，仅记录默认 `ServerUrl=http://127.0.0.1:5858` 和 `AutoStart=true`，未校验 `ServerUrl` 合法性；`Save()` 亦静默吞错，磁盘满或权限不足时用户无感知。
- 位置：src/client-windows/Pim.Client.App/DaemonConfig.cs:16-38
- 问题：
  ```csharp
  public static DaemonConfig Load()
  {
      try { if (File.Exists(FilePath)) { var json = File.ReadAllText(FilePath); return JsonSerializer.Deserialize<DaemonConfig>(json) ?? new(); } }
      catch { } // 吞错，无日志
      return new();
  }
  public void Save()
  {
      try { Directory.CreateDirectory(Dir); File.WriteAllText(FilePath, JsonSerializer.Serialize(this)); }
      catch { } // 吞错
  }
  ```
- 风险：用户手动编辑 config.json 语法错误后配置静默重置为默认值，`ServerUrl` 被重置为 5858 而用户原配置丢失；`Save` 失败无反馈，`AutoStart` 开关状态可能未持久化。
