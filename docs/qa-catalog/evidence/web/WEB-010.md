# WEB-010 | /calendar | 一般 | 日历非分页分支返回List破坏契约
- 描述：`GET /api/v1/calendar/events?start&end` 未带 `page` 时返回 `List<EventResponse>`，而带 `page` 时返回 `PagedResult`，前端 `getEventsPaged` 强制按 Paged 解析会漂移。
- 复现：已登录用户分别请求 `curl -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:5860/api/v1/calendar/events?start=2026-08-23T00:00:00Z&end=2026-08-25T00:00:00Z"` 与 `...&page=1&pageSize=2`，观察返回结构
- 预期：统一返回 `ApiResponse<PagedResult>`
- 实际：前者 `data` 为数组 `[]`，后者 `data.items` 数组
- 证据：`db-write2.cjs` 日志 `pNo 200 data:[...]` vs `p1 200 data:{"items":...}`，截图 `screenshots/calendar.png`
