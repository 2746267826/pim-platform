# WIN-005 | client-windows/AwCollector | 严重 | 同步阻塞调用与无界拉取导致死锁/内存膨胀
- 描述：`FetchNewEvents` 使用 `GetAsync(...).GetAwaiter().GetResult()` 与 `ReadFromJsonAsync(...).GetAwaiter().GetResult()` 在异步上下文中同步阻塞，易在 UI 或带 SynchronizationContext 环境死锁；且 `BuildEventsUrl` 使用 `limit=-1` 无界拉取 ActivityWatch 全量事件，若用户历史累积数万条则一次性加载到 `List<RawAwEvent>` 内存占用激增。
- 位置：src/client-windows/Pim.Client.Core/Services/AwCollectorService.cs:354-376,378-379
- 问题：
  ```csharp
  private static readonly string AwBase = Environment.GetEnvironmentVariable("AW_BASE_URL") ?? "http://127.0.0.1:5600";
  private static string BuildEventsUrl(string bucketId) =>
      $"/api/0/buckets/{Uri.EscapeDataString(bucketId)}/events?limit={ActivityWatchUnboundedLimit}"; // -1 无界
  private List<RawAwEvent> FetchNewEvents(...)
  {
      var response = _aw.GetAsync(url, _cts.Token).GetAwaiter().GetResult(); // 阻塞
      var all = response.Content.ReadFromJsonAsync<List<RawAwEvent>>(cancellationToken: _cts.Token)
          .GetAwaiter().GetResult() ?? new(); // 阻塞
  }
  ```
- 风险：无界数据一次性入内存可能 OOM；在 WPF 同步上下文中调用 `SyncNowAsync` → `CollectAndUploadAsync` → `FetchNewEvents` 时可能死锁；`GetResult()` 异常包装为 `AggregateException` 丢失原始堆栈。
