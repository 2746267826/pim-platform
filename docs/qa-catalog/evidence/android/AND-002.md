# AND-002 | 同步 | 严重 | 数据同步到 pim_test 被 BLOCKED（服务器地址未配置）

- 描述：模拟器上 App 的 `MobileSyncWorker` 日志显示 `Worker result FAILURE`，`shared_prefs/pim_mobile_sync_state.xml` 持续为 `phase=server-missing outcome=BLOCKED progress_text=服务器地址未配置，已跳过同步。`，尽管 `http://127.0.0.1:5858/health` 返回 `healthy` 且 `pim_test` 库中 `mobile_location_points=6224, mobile_usage_sessions=147945` 可查询，但端侧未配置服务器地址导致本地队列无法上传，`dumpsys dbinfo` 显示 `pim.db` 中 `mobile_sync_batches` 等表空且 `pending_queue_count=0`。
- 复现：启动 App 后 `adb shell run-as com.pim.app cat /data/data/com.pim.app/shared_prefs/pim_mobile_sync_state.xml`；`adb shell logcat -d --pid=$(adb shell pidof com.pim.app) | grep -i sync`；`curl http://127.0.0.1:5858/health`；`PGPASSWORD=62f0a50bb963bb648f8e400399def95a psql -h 127.0.0.1 -p 5432 -U opencode -d pim_test -c "SELECT count(*) FROM mobile_location_points;"`
- 预期：定位/Usage 数据应通过 `MobileSyncCoordinator` 上传到 `pim_test`（`mobile_location_points`/`mobile_usage_sessions` 计数增长），`phase` 非 BLOCKED
- 实际：`phase=server-missing outcome=BLOCKED`，`Work FAILURE`，`last_error=服务器地址未配置，已跳过同步。`，服务端健康但端侧未自动指向 `127.0.0.1:5858`，需用户在设置页手动输入服务器地址；此时“数据同步到 pim_test 库验证”无法完成
- 证据：`adb shell run-as com.pim.app cat /data/data/com.pim.app/shared_prefs/pim_mobile_sync_state.xml`、`adb shell logcat -d | grep WM-WorkerWrapper`（`Work FAILURE for MobileSyncWorker`）、`curl 127.0.0.1:5858/health`（`{"status":"healthy"}`）、`psql pim_test`（`mobile_location_points 6224`）、`dumpsys dbinfo`（`pim.db: mobile_sync_batches`）
