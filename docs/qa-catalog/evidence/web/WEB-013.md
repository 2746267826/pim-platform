# WEB-013 | /files | 一般 | 文件分页参数被忽略假分页
- 描述：文件列表假分页，服务端对 `page/pageSize` 不处理，始终返回 `page=1,pageSize=0`，前端传 `page=2&pageSize=2` 仍返回相同结果。
- 复现：分别请求 `GET /files/items?path=/` 与 `GET /files/items?path=/&page=2&pageSize=2` 对比
- 预期：分页生效，page2 返回不同数据或空
- 实际：两次返回完全相同 `{"result":{"items":[],"page":1,"pageSize":0,...}}`
- 证据：`db-write2.log` `filesPag 200 ...` 与 `files 200 ...` 相同
