# WIN-001 | client-windows/AuthService | 严重 | 登录/刷新流程未捕获网络异常可引发未处理异常
- 描述：`AuthService.LoginAsync`/`RegisterAsync`/`RefreshAsync` 直接 awaiting `ApiClient.PostAsync` 未包裹 try/catch，依赖调用方处理。`RefreshAsync` 被 `ApiClient.OnUnauthorized` 回调，若网络不可用或服务端返回非2xx，`EnsureSuccessStatusCode` 抛出的 `HttpRequestException` 将沿 `SendWithAuthRetryAsync` 未捕获路径向上传播，可能导致守护进程同步任务崩溃。
- 位置：src/client-windows/Pim.Client.Core/Services/AuthService.cs:39,51,140
- 问题：
  ```csharp
  public async Task<bool> LoginAsync(string username, string password)
  {
      var result = await _apiClient.PostAsync<ApiResponse<AuthResponse>>("/auth/login",
          new { username, password }); // 无 try/catch
      if (result?.Data is null) return false;
      ApplyTokens(result.Data);
      SaveToken();
      return true;
  }
  public async Task<bool> RefreshAsync()
  {
      if (string.IsNullOrEmpty(_refreshToken)) return false;
      var result = await _apiClient.PostAsync<ApiResponse<AuthResponse>>("/auth/refresh",
          new { refreshToken = _refreshToken }); // 无 try/catch
  }
  ```
- 风险：弱网或API 500时，`AwCollectorService` 定时上传通过 `ApiClient` 调用 `RefreshAsync` 失败未被捕获，`Task.Run` 循环内未处理异常可导致心跳/采集任务意外终止，托盘进程静默失效。
