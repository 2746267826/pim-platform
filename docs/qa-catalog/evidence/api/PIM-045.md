# PIM-045 | Mobile | 严重 | 时序异常：null EndUtc 与 0毫秒窗口违反 start<end

- 描述：脏数据要求插入 `5组null EndUtc` 与 `5组0毫秒窗口`，DB 中 `mobile_usage_sessions` 存在 `end_utc IS NULL`（5行）与 `start_utc = end_utc`（5行，`duration_ms=0`），全局 `284` 行 `start>=end` 违反时序，且聚合侧与 Timeline 侧处理不一致。
- 复现：
  ```bash
  PGPASSWORD=62f0a50bb963bb648f8e400399def95a psql -h 127.0.0.1 -p 5432 -U opencode -d pim_test -c "SELECT count(*) FROM mobile_usage_sessions WHERE end_utc IS NULL;"
  # 5（device session1-device-A）
  PGPASSWORD=62f0a50bb963bb648f8e400399def95a psql -h 127.0.0.1 -p 5432 -U opencode -d pim_test -c "SELECT count(*) FROM mobile_usage_sessions WHERE start_utc >= end_utc AND end_utc IS NOT NULL;"
  # 284 全局（含 5 个 0窗口 + 279 历史）
  PGPASSWORD=62f0a50bb963bb648f8e400399def95a psql -h 127.0.0.1 -p 5432 -U opencode -d pim_test -c "SELECT start_utc,end_utc,package_name FROM mobile_usage_sessions WHERE device_id='session1-device-A' AND (end_utc IS NULL OR start_utc>=end_utc) ORDER BY start_utc;"
  curl -s "http://127.0.0.1:15733/api/v1/mobile/analytics/overview?rangeStartUtc=2026-09-01T00:00:00Z&rangeEndUtc=2026-09-30T00:00:00Z&deviceId=session1-device-A&force=true" -H "Authorization: Bearer $TOKEN_A" | python3 -c "import json,sys; d=json.load(sys.stdin)['data']; print(d['totalForegroundSeconds'])"
  # null 被过滤为0秒，0窗口也被 MinDuration 过滤，但 Timeline 侧 EndUtc null 会拉到 Now 膨胀
  ```
- 预期：所有 `session.start < end`，`null EndUtc` 应拒绝或标记 `open-ended`，`0毫秒` 应拒绝入库。
- 实际：`5 null + 5 zero` 入库，聚合丢弃而 Timeline 膨胀至当前时间，同一行在不同端点时长不一致（见 `MobileUsageAggregationService.cs:255` vs `MobileTimelineBlockService.cs:408`）。
- 证据：`evidence/api/session1/db_snapshot.txt`（`null_end 5, bad_start_ge_end 5, zero_duration 5`）、`evidence/api/session1/temporal_check.txt`、`evidence/pc-aggregation-overlap.sql` 前身 `CATALOG PIM-017`。
