# PIM-044 | Mobile | 严重 | 聚合未去重：重叠会话使单小时 ForegroundSeconds=5400 >3780

- 描述：`MobileUsageAggregationService.LoadRows` 对同一 `device+hour` 多条重叠 `mobile_usage_sessions` 直接相加，未做时间去重，单小时桶 `5400s` 超过物理上限 `3780s`（3600*1.05）。
- 复现：
  ```bash
  API=http://127.0.0.1:15733
  TOKEN_A=$(cat /tmp/token_s1a.txt)
  curl -s "$API/api/v1/mobile/analytics/heatmap?rangeStartUtc=2026-09-01T00:00:00Z&rangeEndUtc=2026-09-30T00:00:00Z&deviceId=session1-device-A&granularity=hour&force=true" -H "Authorization: Bearer $TOKEN_A" > /tmp/heatmap.json
  cat /tmp/heatmap.json | python3 -c "import json; buckets=json.load(open('/tmp/heatmap.json'))['data']; print([b for b in buckets if b['foregroundSeconds']>3780][:3])"
  # 20 个桶 5400s
  PGPASSWORD=62f0a50bb963bb648f8e400399def95a psql -h 127.0.0.1 -p 5432 -U opencode -d pim_test -c "SELECT start_utc,end_utc FROM mobile_usage_sessions WHERE device_id='session1-device-A' AND start_utc>='2026-09-01' AND start_utc<'2026-09-02' ORDER BY start_utc LIMIT 4;"
  # 00:00-00:45 与 00:15-01:00 重叠30分钟，原始合5400，去重应3600
  ```
- 预期：去重后单小时 `<=3780`，且 `qualityFlags` 应标记 `重叠`。
- 实际：`5400` 无标记，20/46 桶超限，最大 `5400`，`tolerance_check.txt` 20 violations。
- 证据：`evidence/api/session1/heatmap.json`（`foregroundSeconds:5400`）、`evidence/api/session1/tolerance_check.txt`、`evidence/api/session1/consistency_check.txt`（`overview total=149400` 原始和=去重1.5倍，`raw 108000 vs dedup 72000`）。
