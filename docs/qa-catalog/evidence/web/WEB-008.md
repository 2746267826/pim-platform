# WEB-008 | /quick-notes | 一般 | 快速记录允许空内容创建
- 描述：后端未校验空内容，前端虽禁用按钮但API直接POST空字符串仍成功创建。
- 复现：已登录 POST http://127.0.0.1:5860/api/v1/quick-notes Body {"contentMarkdown":"","source":"web-page"}
- 预期：400 提示内容不能为空
- 实际：201 返回空内容记录 id 9a5f9143-a35e-4116-a1e7-763f56c2b983，DB中可查到 content_markdown='' 的记录
- 证据：/workspace/pim-platform/docs/qa-catalog/evidence/web/screenshots/quicknotes_empty.png，DB查询 SELECT count(*) FROM quick_notes WHERE content_markdown='' 返回>0
