# WIN-008 | client-shell-windows/ShellConfig | 一般 | 空默认值与静默吞错导致配置丢失
- 描述：`ShellConfig.ServerUrl` 默认空字符串，`Load()` 在文件不存在或 JSON 损坏时 catch 后直接返回 `new()` 空配置，无日志、无备份；`Save()` 直接 `File.WriteAllText` 序列化当前对象，若进程崩溃时写入半截文件，下次加载即判定损坏而丢弃全部配置，用户需重新输入服务器地址。
- 位置：src/client-shell-windows/Pim.Shell.App/ShellConfig.cs:8-33
- 问题：
  ```csharp
  public string ServerUrl { get; set; } = "";
  public static ShellConfig Load(string path)
  {
      try { if (File.Exists(path)) return JsonSerializer.Deserialize<ShellConfig>(File.ReadAllText(path)) ?? new(); }
      catch { } // 静默吞错，无日志
      return new();
  }
  public void Save(string path)
  {
      File.WriteAllText(path, JsonSerializer.Serialize(this)); // 非原子写入
  }
  ```
- 风险：配置损坏静默回退为空，导致 `App.OnStartup` 每次进入 `SetupWindow` 要求重新配置；非原子写入在断电/崩溃时易产生损坏文件，数据丢失。
