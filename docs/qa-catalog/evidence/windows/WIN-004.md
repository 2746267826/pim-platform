# WIN-004 | client-windows/AwCollector | 严重 | 无限重试无退避与次数上限
- 描述：`AwCollectorService.Start` 每 30s 定时执行 `CollectAndUploadAsync`，若服务端持续返回业务错误（Code!=0/200）或 401 刷新失败，仅记录 `LastUploadError` 并在下周期原样重试同一批数据，无指数退避、熔断或最大重试次数。失败时游标不前进 `CommitFetched` 仅在成功后执行，导致同一批数据永久重试。
- 位置：src/client-windows/Pim.Client.Core/Services/AwCollectorService.cs:93-111,145-204
- 问题：
  ```csharp
  public void Start()
  {
      Task.Run(async () => {
          while (!_cts.Token.IsCancellationRequested) {
              await Task.Delay(30_000, _cts.Token);
              await CollectAndUploadAsync(); // 失败仅 Log，无退避
          }
      });
  }
  // CollectBucketAndUploadAsync 仅在 uploaded>0 后才 CommitFetched，失败返回 new(…,0) 导致下次重发全量
  _cursorState.RecordFetched(bucketId, pendingLastId);
  _cursorState.CommitFetched(); // 仅在 try 成功末尾
  ```
- 风险：服务端持续 400/500 时客户端每30s全量重传，浪费带宽、日志刷屏、服务端压力放大；`BackfillAsync` 按 200 分块循环亦无退避，并发回填可能加剧。
