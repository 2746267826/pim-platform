# WEB-012 | /files | 一般 | 文件列表结构异常嵌套result
- 描述：文件列表 `GET /api/v1/files/items?path=/` 返回 `{"data":{"result":{"items"...}}}` 双层嵌套，而 Web `files.ts` 期望 `ApiResponse<PagedResult>`，需 `.data.result` 才能取到，契约不一致。
- 复现：`curl -H "Authorization: Bearer $TOKEN" http://127.0.0.1:5860/api/v1/files/items?path=/`
- 预期：`{"code":0,"data":{"items":...,"page":...}}`
- 实际：`{"code":0,"data":{"result":{"items":[],"page":1,"pageSize":0,...}}}`
- 证据：`db-write2.log` `files 200 ... result...`
