端侧职责边界

两端统一，但尊重平台交互
原生负责采集与状态 Windows 采集 PC 活动；Android 采集移动上下文。每个采集源都有权限、开关、质量、最近上传。
通知负责唤醒和轻操作 需要人工审计的操作用通知触达，并提供详情、稍后、确认等动作。
复杂模块复用 Web 任务、日程、数据中心、Outlook、报告都在内嵌 Web 中保持完整功能。
在线优先 采集可缓存；其他事实变更、同步写回、审计确认和报告交互都在线执行。
