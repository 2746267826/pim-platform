# AND-003 | 同步 | 一般 | 本地 pim.db 空库导致聚合与服务端不一致（启动即空）

- 描述：`adb shell dumpsys dbinfo` 显示 `pim.db` 仅含 `android_metadata` 与 `mobile_sync_batches/mobile_device_profile` 等空表触发器，无业务数据；`adb logcat` 首启有 `Davey! duration=1713ms Skipped 100 frames` 与 `Work cancelled`，说明启动时无历史数据且同步失败，端侧 `Today/Status` 页展示为空，与服务端 `pim_test` 已有 12 万条 sessions 不一致但无错误提示。
- 复现：`adb shell dumpsys dbinfo | grep pim.db`；`adb shell logcat -d --pid=$(adb shell pidof com.pim.app) | grep -E "Davey|Choreographer|Work.*cancelled"`
- 预期：首次启动应提示“无数据”或引导登录/同步，空库与服务端差异应显式标注
- 实际：空库静默展示，`Room` 初始化仅建 `android_metadata`，未加载 `app_usage/mobile_location_points` 等，后续同步又因服务器地址未配而永久空
- 证据：`adb shell dumpsys dbinfo`（`path=/data/user/0/com.pim.app/databases/pim.db` 仅 `room_table_modification_log`）、`adb shell logcat -d | tail`（`Choreographer: Skipped 100 frames!`、`WM-WorkerWrapper: Work was cancelled`）
