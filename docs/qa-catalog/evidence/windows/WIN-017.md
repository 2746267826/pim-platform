# WIN-017 | client-windows/EmbeddedWebViewHost | 严重 | Token 注入 localStorage 持久化可被 XSS 窃取
- 描述：`EmbeddedWebViewHost.InjectAuthTokenAsync` 将 `CurrentAccessToken` 序列化后通过 `localStorage.setItem('accessToken', …)` 注入 WebView，并同时调用 `AddScriptToExecuteOnDocumentCreatedAsync`（持久注入）与 `ExecuteScriptAsync`（立即执行）。`localStorage` 持久化且对页面 JS 完全可读，若 Web 内容存在 XSS 即可窃取。
- 位置：src/client-windows/Pim.Client.App/EmbeddedWebViewHost.cs:65-77
- 问题：
  ```csharp
  var tokenJson = JsonSerializer.Serialize(_authService.CurrentAccessToken);
  var script = $"localStorage.setItem('accessToken', {tokenJson});";
  await View.CoreWebView2.AddScriptToExecuteOnDocumentCreatedAsync(script); // 持久
  await View.CoreWebView2.ExecuteScriptAsync(script);
  ```
- 风险：与 `CATALOG.md PIM-038` 同源；Android 端 `AndroidWebMessageBridge` 仅按需受限返回，二者设计相反；Web XSS → 长期有效 Bearer 泄露，且 `localStorage` 不会随进程退出清除。
