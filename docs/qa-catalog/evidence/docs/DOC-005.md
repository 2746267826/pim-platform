# DOC-005 | AGENTS.md | 严重 | Token 禁止进入 WebView 规范被 Windows 客户端违反
- 描述：AGENTS B5 要求 Tokens 仅在内存或加密存储，永不进入 WebView，但 Windows 客户端将 accessToken 持久注入 localStorage。
- 文档位置：AGENTS.md:94-95 B5 节 `Tokens live in memory or encrypted storage only — never in WebView or uploads.`
- 文档承诺：Token 不得进入 WebView，禁止明文落盘
- 代码实际：`src/client-windows/Pim.Client.App/EmbeddedWebViewHost.cs:73` `localStorage.setItem('accessToken', tokenJson)` 通过 `AddScriptToExecuteOnDocumentCreatedAsync` 与 `ExecuteScriptAsync` 持久化；`src/client-windows/Pim.Client.Core/Services/AuthService.cs:101` `File.WriteAllText(JsonSerializer.Serialize(data))` 明文明文写 `%LOCALAPPDATA%/PIM/token.json`
- 差异：代码将 Bearer Token 暴露于 WebView localStorage 与明文文件，XSS 或本地文件读取即可窃取，与文档安全红线直接冲突
